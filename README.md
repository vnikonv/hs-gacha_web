## A Website for ISTA 498 Capstone Project: Homestuck Gacha

This informative website integrated with Google Analytics will
be used to better understand our game's target audience and
publish our progress to the public.

### Goals:
- Reach potential players
- Collect information on the people interested in playing the game
- Show what the project is capable of being, potenially

### Architectural features:
- Static content served
- Browser JavaScript on client side
- Engagement trackers reporting to Google Analytics
- Docstrings, changelog, and file versioning
- Section-separated webpage structure
